# 🏨 Hotel Tramonto

Sistema web para la gestión de un hotel, desarrollado como proyecto académico para la Licenciatura en Sistemas de Información.

## 📋 Descripción

Hotel Tramonto es una aplicación web desarrollada con Laravel que permite gestionar información y operaciones relacionadas con la administración de un hotel.

El proyecto fue desarrollado como parte de la formación académica, aplicando conceptos de desarrollo web, programación orientada a objetos, bases de datos y arquitectura MVC.

## 🛠️ Tecnologías

- PHP
- Laravel
- MariaDB
- HTML
- CSS
- JavaScript
- Git
- GitHub

## 📌 Características

- Gestión de información del hotel
- Gestión de usuarios
- Gestión de habitaciones
- Gestión de reservas
- Operaciones CRUD
- Persistencia de datos
- Relaciones entre entidades
- Validación de datos

## 🗄️ Base de datos

El proyecto utiliza MariaDB como sistema de gestión de base de datos y Laravel Eloquent para la interacción con los datos.

## 🏗️ Arquitectura

El proyecto utiliza el patrón de arquitectura MVC (Model-View-Controller) proporcionado por Laravel.

- **Models:** representación y gestión de los datos.
- **Views:** interfaz de usuario.
- **Controllers:** lógica de la aplicación.
- **Routes:** definición de las rutas de la aplicación.
- **Migrations:** estructura de la base de datos.
